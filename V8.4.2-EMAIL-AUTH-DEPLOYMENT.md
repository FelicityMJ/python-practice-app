# v8.4.2 school email/password deployment

## 1. Firebase Authentication

Firebase Console → Authentication → Sign-in method:

- Enable **Email/Password**.
- Google is not required for the v8.4.2 interface. It can remain enabled temporarily if old test accounts exist.

Firebase Console → Authentication → Settings → Authorised domains:

- Add `nat5computing.co.uk`
- Add `www.nat5computing.co.uk`
- Keep the Firebase-provided domains.

## 2. Deploy Firestore rules first

Deploy the included `firestore.rules` before letting a new classroom pupil or teacher create an account. The new rules allow email/password school identities and require verified email before school learning data can be used.

## 3. Approve a teacher

Before the teacher uses **First-time setup**, create this Firestore document:

`teacherInvites/teacher@school-domain.example`

Use the exact email address in lowercase. Suggested fields:

```text
active: true
displayName: "Teacher name"
```

Then the teacher:

1. Opens **Teacher → First-time setup**.
2. Enters that approved school email address.
3. Creates a Nat 5 Computing password.
4. Opens the Firebase verification email and clicks the link.
5. Returns to the site and signs in through **Teacher → Sign in**.

The normal `users/{uid}` teacher profile is created on the first verified sign-in.

## 4. Classroom pupil flow

1. Teacher creates a class and gives pupils the class code.
2. Pupil chooses **Classroom pupil → Join a class**.
3. Pupil enters class code, display name, school email and a new Nat 5 Computing password.
4. Pupil clicks the Firebase verification link sent to the school email address.
5. Pupil returns to **Classroom pupil → Sign in** and uses email + password.
6. The class code is not required again.

## 5. Personal Study

Personal Study is unchanged. Existing licensed users continue to use the right-hand Personal Study card with their existing email and password.

## 6. Files to publish

Publish at least:

- `index.html`
- `app-v8-4-2.js`
- `styles.css`
- all existing JS/assets already used by the application

Deploy `firestore.rules` through Firebase. GitHub Pages will publish the website files from the repository.

## 7. Test before using with a class

### Teacher
- Approved email can create account.
- Unapproved email is rejected.
- Unverified teacher cannot open dashboard.
- Verified teacher can sign in and create a class.
- Forgot password sends a reset email.

### Classroom pupil
- Invalid class code is rejected.
- Valid class code creates an account.
- Unverified pupil cannot open class learning data.
- Verified pupil can sign in without the class code.
- Teacher can see the pupil in the class.
- Forgot password sends a reset email.

### Personal Study
- Existing Personal Study account still signs in.
- It is rejected if entered in the classroom card and accepted in the Personal Study card.
