# v8.3.2 authentication setup

This version does **not** require the v8.3.1 password-reset Cloud Function.

## 1. Firebase Authentication providers

In Firebase Console → Authentication → Sign-in method, make sure these providers are enabled:

- **Email/Password**
- **Google**

Google is already used by the teacher login in this project, so it may already be enabled.

## 2. Authorised domains

In Firebase Authentication settings, make sure the domain where the site is hosted is listed as an authorised domain. Keep the Firebase-provided domains as well.

## 3. Email templates

In Firebase Authentication → Templates, review the:

- Email address verification template
- Password reset template

The default templates work, but before a real pupil launch you should customise the sender name/wording so pupils recognise Nat 5 Computing.

## 4. Deploy Firestore rules

Deploy the included `firestore.rules`. They now:

- accept new school pupils authenticated by Google or email/password
- require the stored pupil email/username to match the authenticated email
- require a verified email identity before school-class data can be used

## 5. Deploy the website

Deploy/upload at least:

- `index.html`
- `app-v8-3-2.js`
- `styles.css`
- `firestore.rules` (through Firebase rules deployment)
- the existing supporting JS/assets used by the application

There is no Functions deployment step for v8.3.2.

## 6. Test: email + password pupil

1. Teacher creates a test class and copies its class code.
2. Open the site in a private/incognito browser window.
3. Choose **Create pupil account**.
4. Enter class code, display name, a real test email and a password.
5. Confirm that the app says a verification email was sent.
6. Try signing in before verifying: access should be blocked and another verification email offered automatically.
7. Click the verification link in the email.
8. Sign in using only email + password (no class code).
9. Confirm the pupil dashboard opens and the teacher sees the pupil in the class.
10. Sign out, choose **Forgot password?**, enter the email and confirm the reset email arrives.

## 7. Test: Google pupil

1. Open **Create pupil account** in a private/incognito window.
2. Enter the class code and display name.
3. Choose **Continue with Google and join class**.
4. Select a Google account that is not already a teacher account.
5. Confirm the pupil dashboard opens.
6. Sign out.
7. On **Pupil sign in**, choose **Continue with Google** without entering a class code.
8. Confirm the same pupil account and progress open.

## 8. Teacher regression check

Confirm that the existing **Teacher → Continue with Google** button still opens the teacher dashboard and that the teacher can view the new pupil's email address in the pupil list/profile.
