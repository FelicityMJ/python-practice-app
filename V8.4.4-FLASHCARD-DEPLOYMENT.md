# v8.4.4 Flashcard deployment

## GitHub files required for the update
Commit these four live-site files:

1. `index.html`
2. `app-v8-4-4.js`
3. `styles.css`
4. `firestore.rules`

Keep the existing `revision-fluency-v8-1-2.js` in the repository. It is unchanged and contains the approved 197-card bank used by v8.4.4.

The release notes and README are optional for the live site but recommended for version history.

## Firebase rules
The v8.4.4 rules add `personalRevisionCards`. Publish the included `firestore.rules` in Firebase before pupils create personal cards.

The rules allow a signed-in pupil to read/write only personal revision cards whose `userId` matches their own Firebase uid.

## Authentication
No change from v8.4.3:
- Email/Password enabled.
- No teacher or pupil email verification step.
- Teachers still require an active `teacherInvites/{email}` document.

## Quick test
1. Sign in as a pupil.
2. Open Revision Hub.
3. Confirm the setup reports 197 course cards when **Include all 197 approved course cards** is ticked.
4. Select an area and topic and run a 5-card session.
5. Confirm typed answer -> compare -> marking points -> confidence rating -> next card.
6. Rate one card Not secure and confirm it returns later in the same session.
7. Add a personal flashcard using an existing topic.
8. Add another personal flashcard using **+ Create new topic…**.
9. Edit and delete a personal flashcard.
10. Export the personal cards, then re-import the JSON file.
11. Sign out and back in (or use another device) and confirm the personal cards remain available.
